# Wireshark Network Traffic Analysis

Network Traffic Analysis and Basic Threat Detection using **Wireshark**.

---

## Project Overview

This project demonstrates practical network traffic analysis using Wireshark by examining a real packet capture (PCAP) file. Multiple network protocols including DNS, TCP, UDP, ICMP, ARP, and TLS were analyzed to understand communication patterns, endpoint interactions, protocol behavior, and network troubleshooting techniques.

---

## Objectives

- Capture and inspect network traffic
- Analyze common network protocols
- Understand TCP communication and handshakes
- Examine DNS requests and responses
- Investigate ARP and ICMP packets
- Analyze encrypted TLS traffic
- Identify communicating endpoints
- Study protocol distribution and conversations
