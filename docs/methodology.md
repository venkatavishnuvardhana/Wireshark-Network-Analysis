# Methodology

## Step 1

Launch Wireshark and select the active network interface.

## Step 2

Start packet capture.

## Step 3

Generate network traffic by:

- Browsing websites
- Running ping commands
- Performing DNS lookups

## Step 4

Stop packet capture after approximately 5–10 minutes.

## Step 5

Apply protocol filters including:

- dns
- tcp
- udp
- icmp
- arp
- http
- tls

## Step 6

Analyze:

- Source IP
- Destination IP
- Protocol
- Packet Length
- TCP Flags
- DNS Queries
- TLS Handshake

## Step 7

Document observations and security findings.
